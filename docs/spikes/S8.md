**Findings**
1. **The main aux has unit-specific content in three forms:**
   - immediate or delayed writes inside unit slices (`\BKM@entry`, `\abx@aux@cite/segm`, `\pgfsyspdfmark`);
   - glue writes that may be flushed inside a unit slice (`\appendix`);
   - **end-of-document aggregates** over the segments typeset in the run (eqparbox tags, KOMA autodot flag).
2. **Aggregates cannot be taken from one run.** eqparbox data are per tag; a tag belongs to the units whose runs wrote it (the tags here contain the chapter number). The KOMA flag is an OR over all segments.
3. **Aux records span several lines** (`\@setckpt`, `\LT@…`): the parser must read brace-balanced statements, not lines.
4. `\pgfsyspdfmark` (positions for `remember picture`, used by todonotes margin notes and tikz overlays) is *self*, keyed by `pgfidN`. `pgfidN` is numbered by `pgf@picture@serial@count`, which is restored by S4.

**Consequences for the plan (§6.7.2, §6.6)**
- **Canonical main aux** = the main aux of the run that committed the glue, with:
  - per unit: the unit-content kinds (`\BKM@entry`, `\abx@aux@cite`, `\abx@aux@segm`, `\pgfsyspdfmark`, fastinc records) replaced by those of the unit's committed slice; other kinds keep the glue run's positions;
  - end-of-document aggregates merged:
    - eqparbox per tag, from the latest run that wrote the tag; the tag's owner is the set of units in that run;
    - KOMA flag as OR, attributed to the run's included units, class *global* (a change dirties all);
    - `\abx@aux@defaultrefcontext` per key; `\abx@aux@read@bbl*` ignored; `\@abspage@last` rewritten.
- Unknown end-of-document kinds: *global* with a warning (as before).
- The aux parser works on brace-balanced statements.
