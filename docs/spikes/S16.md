# S16: cleveref

**Question.** `cleveref` was on the list of packages that force full builds (design §1,
`facts.UNSUPPORTED_PACKAGES`) together with packages that write their own index or glossary
files or need shell escape, which cleveref does not; no reason was recorded. In a sweep of
public theses it was the second most common reason for full builds. Does the incremental
build handle it?

**Setup.** TeX Live 2026, dev image. `tests/corpus/minimal/S16-cleveref/` (`book`, amsthm,
hyperref, bookmark, cleveref with `capitalise`; three `\include`s): `a` refers to labels of
`b` and `c` with `\cref` (one and two keys), `\Cref`, `\crefrange`, `\cpageref`, and to a
theorem relabelled with `\label[lemma]{thm:alias}`; `b` refers back with `\cref`. The driver
was patched to allow cleveref; each step builds with `--check`, with `-j 1` and `-j 4`.

## Results

cleveref patches `\refstepcounter` and writes a second entry per label into the aux file:
`\newlabel{<key>@cref}{{[<type>][<counter>][<reset path>]<number>}{[..][<page>][..]<page>}}`.
`\cref{<key>}` prints the type name and number from it.

| Step | Compiled | §3.3 |
|---|---|---|
| cold | all | pass |
| typo in `c` | `c` | pass |
| figure inserted before `fig:b1` (numbers change) | `b`, then `a`, `c` | pass |
| `a` longer (pages of `\cpageref` targets change) | `a`, `b`, `c` | pass |
| `\label[lemma]{thm:alias}` → `\label[theorem]{thm:alias}` | `c` only | **fail** |

The last step changes only `thm:alias@cref` (`[lemma]` → `[theorem]`); `thm:alias` keeps
number, page and anchor. The dependency model imports the key the source names
(`thm:alias`), so `a` was not recompiled and kept "Lemma 3.2" where the reference prints
"Theorem 3.2". Changes of a number or page change both entries.

## Consequence

`deps.label_values`: the value of a label includes its companion labels
(`deps.COMPANION_LABELS`, `@cref`); with that the last step compiles `c` and `a` and passes.
`STATE_VERSION` 6 (stored import values change meaning). cleveref is removed from
`facts.UNSUPPORTED_PACKAGES`; design §1, §6.8.1. Scenario test
`test_cleveref_across_units` (`-j 1` and `-j 4`).
