# S2 — output directory, stale files, shadow tree; S2b nomencl write mode

**Setup.** TeX Live 2026, dev image. Reproducer: `tests/corpus/minimal/S2-paths/` (`./run.sh OUT`).
- Test document: `article`, biblatex+biber, `\graphicspath{{fig/}}` with a local `fig/a.pdf`, hyperref, `\include{chap/unit}` from a subdirectory, a ToC.
- `run.sh` copies the sources to a "user source dir" and plants stale `main.aux`, `chap/unit.aux` and `main.toc` there, each with a marker string. Then it builds in the variants below.

**Results**

| Case | Result |
|---|---|
| Plain source dir with stale files, **fresh** output dir, 1 pass | **Stale files are read.** The PDF shows all three markers. Read order: the output directory first, then the working directory as fallback. `.fls` shows `INPUT ./main.aux`, `./chap/unit.aux` and `./main.toc` at `\begin{document}`. |
| Same, full build into the same output dir | No markers. Once the output directory holds a file, it wins over the working directory. |
| Shadow tree (`cp -as`, build outputs removed), fresh output dir without `chap/` | `I can't write on file 'chap/unit.aux'`. Subdirectories for `\include` paths must exist in the output directory (already in PLAN §6.5). |
| Shadow tree, output dir with `chap/` | No markers. 3/3 pages raster-identical to a build from a clean copy, text identical. Graphics via symlink: `<use fig/a.pdf>`. biber via symlink: `Found BibTeX data source 'refs.bib'`. |
| SyncTeX paths | Recorded as `<absolute cwd>/./<relative path>`, unresolved (shadow paths, not the symlink targets), e.g. `/…/shadow/./chap/unit.tex`. `synctex view -i 2:1:chap/unit.tex` gives the same page, h and v as the reference. `synctex edit` returns `…/shadow/./chap/unit.tex`, line 2. |
| S2b: nomencl write mode | `\makenomenclature` uses `\immediate\openout`. Entries are written with `\protected@write` (delayed, at shipout). Segment markers in `.nlo` must therefore also be delayed writes. |
| `TEXMF_OUTPUT_DIRECTORY` | Not needed. The driver calls biber and makeindex itself, with explicit directories. |

**Consequences for the plan**
- The shadow tree (§6.5) is necessary: without it, any aux or derived file missing from a run directory falls back to a stale copy in the source directory. It works for `\include` subdirectories, `\graphicspath`, graphics and `.bib`.
- SyncTeX and log path mapping (§6.2, §6.12): normalise `/./`, then substitute the shadow-tree prefix with the source directory. Paths are absolute.
- §6.5 run preparation: create the `\include` subdirectories in the run directory (confirmed necessary).
