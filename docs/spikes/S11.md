# S11 — MiKTeX

**Question (PLAN §9, §6.16).** MiKTeX: format flags, output-directory read order (S2 repeated),
on-the-fly installation, `SOURCE_DATE_EPOCH`, availability of mylatexformat, biber, makeindex,
synctex. Does chapmk work with MiKTeX, and what does the MiKTeX adapter have to change?

**Setup.** MiKTeX 26.5 on Ubuntu 24.04 (`Dockerfile.miktex`: complete MiKTeX without docs and
sources, on-the-fly installation off). Reproducers in `tests/corpus/minimal/S11-miktex/`:
- `run.sh OUT`: one block per question; repeats S2 (`../S2-paths/run.sh`) and the S1 identity
  check with a format;
- `probe_chapmk.py`: chapmk end to end with a minimal spike adapter (subclass of `TeXLive`),
  thesis cold build, typo, page shift with `-j 4`, pictures corpus, each with `--check`.

Windows is not covered here: the manual workflow `.github/workflows/miktex.yml` (Chocolatey
MiKTeX) is the next step.

| 7 | SyncTeX paths | Absolute and unresolved (shadow-tree paths, not symlink targets), but **without `/./`**: `/…/shadow/chap/u.tex` (TeX Live: `/…/shadow/./chap/u.tex`). `synctex view -i L:C:<relative>` therefore finds nothing (also for a plain MiKTeX build); absolute paths work. |

## Consequences for the plan

- **MiKTeX adapter (`texdist.MiKTeX`)**, differences to `TeXLive`:
  - detection by `pdflatex --version` ("MiKTeX"), not by the path;
  - format use: `--undump=<absolute path to <fmt_dir>/<name>.fmt>` instead of `-fmt=<name>` plus `TEXFORMATS`;
  - `--max-print-line=10000` on every TeX call instead of the environment variable;
  - the SyncTeX form of a source path (`<cwd>/<rel>`, no `/./`), used by the merge for the main file and by the path mapping;
  - `SOURCE_DATE_EPOCH`/`FORCE_SOURCE_DATE`, `TEXINPUTS`, biber and makeindex calls: as TeX Live.
- **SyncTeX (§6.5, §6.12):** the path mapping must not assume `/./`; the main-file path in the merged file comes from the adapter.
- **`check` (§3.3 item 4):** sample SyncTeX with absolute source paths. With relative ones, MiKTeX finds nothing on both sides and the comparison passes without comparing anything. To verify under TeX Live (whether absolute queries match `<cwd>/./<rel>` records); otherwise the adapter supplies the query form.
- **Shadow tree (§6.5):** required under MiKTeX for every input, not only for stale files from manual builds: the working directory always wins over the output directory.
- **§6.16 table:** `SOURCE_DATE_EPOCH` supported (no `\today` override); no `--aux-directory` needed.
- **Corpora:** hgb needs a variant that works with the `hgbthesis` in MiKTeX (or is skipped for MiKTeX with that reason).
- **Open for Windows (CI):** drive letters and backslashes in `.fls`/SyncTeX paths, symlink fallback of the shadow tree, on-the-fly installation, viewer locks.
