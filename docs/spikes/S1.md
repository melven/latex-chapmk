# S1 — mylatexformat with the thesis preamble

**Setup.** TeX Live 2026 (pdfTeX 1.40.29, LaTeX 2026-06-01), dev image. Reproducer: `tests/corpus/minimal/S1-format/`
(`main.tex` = corpus preamble + small body with ToC, nomenclature, citations, `\todo`, siunitx, refs;
`./run.sh OUT 41 42 193`). Each variant gets a full build (pdflatex, biber, makeindex, pdflatex ×2) and is compared with a plain build:
- `pdftoppm -r 150` page rasters;
- `pdftotext -layout`;
- `synctex view` at 5 body lines;
- outline and page labels.

**Questions and results**

| Question | Result |
|---|---|
| Dump OK when split before `hyperref` (line 41)? | Yes. 8.1 MiB format. |
| Can `hyperref` and `biblatex` go into the format? | Yes. Splits before line 42 (after hyperref) and before line 193 (everything except the `\ifdraft{\tikzexternalize…}` block) are also identical. |
| Runtime skip semantics | At job start, mylatexformat (`\everyjob`) scans the main file line by line. It discards lines until one contains `\endofdump`, `\csname endofdump\endcsname` or `\begin{document}`, then executes that whole line. Blank lines 1..s-1 plus `\csname endofdump\endcsname` prefixed to line s work (log: `start reading document "main"`). |
| SyncTeX with the format | Works. `synctex view` results are identical to the plain build, and line numbers are preserved. |
| `\makenomenclature` deferral | **Not needed.** During the dump, mylatexformat redefines `\openout` to collect the opens and replays them at runtime, with `\jobname` expanded then. The log shows `\openout4 = 'main.nlo'`. |
| `\jobname` frozen as `pre`? | No stray `pre.*` files in run directories. |
| Output equality | 9/9 pages raster-identical, text identical, outline and page labels identical, for all three splits. |
| Time per pdflatex pass (this small body) | Plain 2.9–3.4 s. Format split at 41: 1.1–1.3 s. Split at 193: 0.95–1.1 s. |

**Further findings**
1. **`-fmt=<absolute path>` breaks `-recorder`.** pdflatex builds the temporary `.fls` name from the format path (`<outdir>//abs/path/pre38.fls: No such file or directory`). Fix: pass the format by name and set `TEXFORMATS=<fmtdir>:`.
2. **makeindex refuses absolute output paths** (`openout_any = p`). Run it in the output directory with relative names (already the plan in §6.10).
3. **scrbook loads the `bookmark` package automatically when hyperref is present** (KOMA option `bookmarkpackage`, default true). `bookmark` is a non-goal in PLAN §1, so the reference document would always fall back to full builds. **Decision point.**
   - `bookmark` writes the outline as `\BKM@entry{id=N,dest={<hex>},srcline={L}}{<hex title>}` lines into the current aux file, so each unit's entries land in its own aux. It does not use the `.out` stream.
4. The deny-list match `\tikzexternalize` is on line 194, inside the brace group `\ifdraft{…}` opened on line 193. A split point inside a group would break the dump. The split point must move to the start of the top-level preamble command containing the match.
5. The log differs, without any output difference: the plain build warns `Unused \captionsetup[subfigure]`, the format builds do not. Logs are not part of §3.3.
6. **Corpus:** `\Rn` is defined by biblatex, so the preamble's `\renewcommand{\Rn}` is correct.

**Consequences for the plan**
- §6.3.2: `hyperref` no longer on the deny list. Split points are moved to the start of the enclosing top-level command.
- §6.3.3 / §6.4.1: `\makenomenclature` deferral removed (mylatexformat replays `\openout`). The deferral table remains as a contingency for writes that mylatexformat does not catch.
- §6.3.1 / §6.16: the format is passed via `TEXFORMATS` and a relative name.
- `bookmark` (finding 3): pending decision.
