# S18: state left open at the end of a unit

**Question.** pdfrender (`\textpdfrender{TextRenderingMode=Invisible}{…}`) came up as a
possibly unsupported package. Does it merge, and what happens to state a unit leaves open
for the next one?

**Setup.** TeX Live 2026, dev image. `tests/corpus/minimal/S18-unit-state/` (`book`, xcolor,
pdfrender, three units). Per case unit `a` ends with a state switch at its top level; cold
build, typo in `b`, `--check`.

## Results

pdfrender itself merges: its render mode is kept in its own colour stack and each page carries
its state (cold build, typos in each unit, a mode across a page break, `-j 1` and `-j 4`: all
pass, only the edited unit compiled).

State left open at the end of a unit:

| Switch at the end of `a` | Typo in `b` (a run without `a`) |
|---|---|
| `\color{red}`, `\pdfrender{…}`, `\bfseries`, `\sffamily`, `\small`, `\raggedright`, `\linespread{1.6}\selectfont`, `\pagecolor{yellow}` | **wrong output** (only `--check` notices) |
| `\selectlanguage{ngerman}`, `\pagestyle{empty}` | correct (lint: global commands) |
| colour reset before the end, colour in a group, `\textcolor` | correct |

The state vector carries counters and marks only; the lint knew definitions and settings, not
these switches. `\pagecolor` sets the page colour globally (`pdftex.def`).

Options considered: (A) lint the switches at the top level of a unit (the unit becomes global);
(B) record font, colour, render mode and paragraph shape at the start and end of each unit and
treat units whose end state differs as global (prototype: exact, 0 of 43 units in five
documents); (C) restore that state at the end of excluded units. A lint prototype flagged 54 of
731 units of local documents; most hits were in macro arguments (`\parbox{…}{\centering …}`,
`\centerline{\itshape …}`) or brace groups after an argument, which the lint takes for
arguments.

## Consequence

User decision: A, with a warning (a switch left open is bad style and probably not
intended). `lint.STATE_COMMANDS` are a hit only outside every group, a macro argument counting
as a group; `\pagecolor` and `\nopagecolor` are global commands (separate change). The lint
cache key includes `LINT_RULES`. Design §6.8.4. Tests: `test_state_left_open_at_the_end_of_a_unit`
(six switches; fails without the rule), `test_lint_state_switches_at_the_top_level`.
