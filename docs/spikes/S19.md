# S19: anchors used across files

**Question.** Sweep category C1 (issue #78): in three documents a ToC entry or bookmark after
the last `\include` points to the wrong page. What causes it, and how can incremental builds
reproduce the plain build?

**Setup.** TeX Live 2026, dev image. `tests/corpus/minimal/S19-anchors/` (`scrbook` with
`listof=totoc`, hyperref, bookmark, three units; after the last `\include`: `\listoffigures`,
`\addcontentsline{toc}{chapter}{REFERENCES}`, `\label`, `\ref`, `\nameref`). `gen_cases.py`
writes ten variants (KOMA and `book`, manual `\addcontentsline`, `\chapter*` and `\addchap` at a
unit's start, biblatex `heading=bibintoc`, each with and without `\phantomsection`);
`run_cases.sh` builds each cold and after a typo in `a`, with `--check`.

## Results

**Cause.** `\addcontentsline` (hyperref) takes its link target from `\@currentHref`, `\label` its
number and target from `\@currentlabel`, `\@currentcounter` and `\@currentHref`: the *last*
anchor before it. KOMA's `\chapter*` sets no anchor with hyperref (`book`'s does:
`chapter*.N`), and `listof=totoc` is `\chapter*` plus `\addcontentsline`
(`tocbasic.sty`). After the last `\include`, the anchor is the last one of the last unit
(`section.6.2`): the ToC entry and bookmark of the list link there, *also in a plain build*
(page 8 instead of 10 in the reproducer). A run that excludes that unit has an older anchor
(`Doc-Start`, page 1), so `--check` fails. The same holds for a manual `\addcontentsline`
before a list or bibliography (alorenzo175) and for KOMA's `\chapter*` +
`\addcontentsline` at the start of a unit. No KOMA bug report was found; the usual fix in a
document is `\phantomsection` before the `\addcontentsline` (after the page break:
`\cleardoublepage\phantomsection`).

**First approach, dropped: carry the anchor macros** in the state vector (digests of the
text, restored at excluded units' checkpoints, like the marks). Correct, but the anchor names
of starred sections contain hyperref's document-wide `\Hy@linkcounter` (`section*.17`), while
a digest can only be predicted as unchanged: a new figure in an early chapter mispredicted the
exit of every later chapter ending with `\section*` (thesis corpus, T9: extra batches of all
later units). The units read the value only in the rare cases above.

**Second approach: detect the use.** `chapmk.sty` takes a snapshot of the anchor macros at
each segment start; hooks on `\addcontentsline` (with hyperref only: the kernel's writes no
target) and `\label` write `R <seg> <command> <line>` if they see the start value. `H <seg>`
marks a segment that ends with an anchor of its own. Two refinements were needed:

- A value comparison alone confused a name set again with an unchanged one: after KOMA's
  `\chapter*` or `\addchap` the section numbers restart, and `section.1.2` of `b` equals the
  last anchor of `a`. The names created in a segment (`\hyper@anchorstart`) and the counter
  numbers (`\refstepcounter`) are registered; only a start value not created again counts.
  A float's anchor is local, so the value comparison stays the basis.
- `\@currentlabel` alone is not unique ("2.1" of a section and of a table, hgb corpus): the
  number counts as old only with the same `\@currentcounter`.

| Case | Records | `--check`, typo in `a` compiles |
|---|---|---|
| KOMA `listof=totoc`, manual `\addcontentsline` + `\label` after the last include | `R G3`, owner `c` | pass; `a`, `c` |
| the same with `\cleardoublepage\phantomsection` | none | pass; `a` |
| biblatex `heading=bibintoc` (KOMA, `book`) | none (own anchor) | pass; `a` |
| `\chapter*` + `\addcontentsline` at the start of `b`, `c`: `book` | none | pass; `a` |
| the same in `scrbook` | `R U2 1`, `R U3 1`, owners `a`, `b` | pass; all |
| the same with `\phantomsection` after `\chapter*`; `\addchap` | none | pass; `a` |
| thesis, hgb, pgfmanual (cold builds) | none | – |

## Consequence

User decision (issue #78): the unit whose anchor a later segment uses is *global* (compiled in
every run), with a warning naming the command's line and the fix; no state is carried.
Design §6.8.4 (at run time), Appendix B (`H`, `R`). Tests:
`test_anchor_of_the_last_unit_used_after_it`, `test_anchor_used_at_the_start_of_a_unit`,
`test_contents_line_before_the_bibliography`, `tests/unit/test_sources.py`.
