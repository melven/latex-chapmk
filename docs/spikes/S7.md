# S7 — running heads in partial vs full runs

**Setup.** TeX Live 2026, dev image. Reproducer: `tests/corpus/minimal/S7-marks/` (`./run.sh OUT`, `pagecmp.py` compares each partial-run page with the full-run page of the same label as a 60 dpi raster, including the heads).
- Test document: `scrbook`, twoside, `\pagestyle{headings}`, hyperref (for page labels).
- Units:
  - u1: `\chapter{Alpha chapter}`, two sections, several pages;
  - u2: **violates A5**, continues chapter Alpha with text, then `\section{Alpha three}`;
  - u3: **violates A5**, starts with `\section{Alpha four}`, no chapter;
  - u4: `\chapter{Beta chapter}`.
- Runs: converged full build, then one pass with `\includeonly` per unit.

**Results**

| Partial run | Pages identical to full run | Difference |
|---|---|---|
| `{u1}` (A5 holds) | 3/3 | — |
| `{u2}` (violates A5) | 1/3 | pages 4 and 6: left head "1 Alpha chapter" missing |
| `{u3}` (violates A5) | 1/2 | page 8: left head missing |
| `{u4}` (A5 holds) | 3/3 | — |

1. **Running heads differ between partial and full runs** for units violating A5. The mark state (chapter mark) of the excluded predecessor is lost. Units starting with `\chapter` are unaffected: the chapter page has no head, and `\chapter` sets the marks before the next page.
2. **Fix attempt 1: carry the kernel mark state** (`s7marks.sty`).
   - Method: record `\g__mark_page_last_<class>_tl` for `2e-left`, `2e-right` and `2e-right-nonempty` at `include/after` (as `{id}{content}`, because the aux is read with document catcodes) and set them again for excluded units.
   - The records are correct, e.g. `\sseven@mark{2e-left}{1}{1\hskip .5em\relax Alpha chapter}`.
   - **No effect**: the same pages differ. The heads of `scrbook`/`scrlayer` still use TeX's primitive marks (`\botmark`/`\firstmark`), whose top value can only come from a real `\mark` node.
3. **Fix attempt 2, analysed but not implemented: inserting a `\mark`** with the recorded values at the excluded unit.
   - The inserted mark becomes the *first* mark of the next page, not its top mark.
   - On a page that sets its own section mark, `\firstmark`, and with it `\rightmark`, would then differ from the full run.
   - So this is only a partial fix, and it is fragile.

**Decision point (CLAUDE.md):** running heads differ for units violating A5. Options are in the conversation; the consequence goes into the plan after the decision.
