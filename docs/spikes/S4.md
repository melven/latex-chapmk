# S4 — `\count` register vectors, restore of excluded units

**Setup.** TeX Live 2026, dev image. Reproducer: `tests/corpus/minimal/S4-registers/` (`./run.sh OUT [norestore|restore]`).
- Test document: corpus preamble plus four `\include` units with equations, theorem, footnote, figure, booktabs/multirow/makecell table, longtable over a page break, algorithm with `\COMMENT`, listing, enumerate, subfigures, tikzpicture, `\section*`, cross-references, citations, nomenclature, `\todo`, `\foreignlanguage`, `\appendix`. Glue has ToC, LoF, LoT, list of todos, nomenclature and bibliography. 21 pages.
- `s4probe.sty` writes all `\count0..\count10` values at every segment entry and exit (immediate write, about 2.5 KB per record).
- Runs: a converged full build, then single passes with `\includeonly` = `{u1}`, `{u2}`, `{u3}`, `{u4}`, `{}` and `{u1,u3}`.
- Comparisons:
  - the vectors against the full run (`analyze.py`; names from the run log plus the `pdflatex.fmt` build log);
  - every partial-run page against the full-run page with the same label (`pagecmp.py`, 60 dpi raster).

**Enumeration**
- Allocated `\count` registers: `\count0..\count10` (`\newcount` increments `\count10`, then jumps to 266 when the classic range is exhausted). 547 registers here.
- Every allocation is logged as `\<name>=\count<n>`, so the driver gets the number↔name map from the format and run logs.
- Kernel boundary: `\count10` = 275 before `\documentclass` (TL 2026).
- `c@LT@tables` = `\count458` (`\newcount`, **not** in the kernel checkpoint), `Hy@linkcounter` = 514, `c@bookmark@seq@number` = 523, `pgf@picture@serial@count` = 485. All are covered by the vector.

**Results**

1. **Without restore** (kernel checkpoint only), the excluded units' state is lost for real state registers: `Hy@linkcounter`, `blx@sectionciteorder@0` (biblatex citation order), `pgf@picture@serial@count`, `enit@count@id`, `LT@rows`, `lst@lineno` and others. One page of `p-u3` (u3's first page) differs from the full run.
2. **Restoring all registers** (kernel ones included) breaks runs. Kernel registers include expl3 locals (`\l__cmd_current_arg_int`), the absolute shipout counters and the float-box insert counts (`\count245–252` = `\bx@A…`). Kernel registers must not be restored.
3. **Restoring all registers allocated after the kernel** (index > 275) is safe except for **run-local** registers, which number objects created in the current run:
   - `BKM@id` (bookmark): restoring it causes `Missing number` at the next `\chapter`, because `bookmark` looks up macros of entries that exist only in the run;
   - `Hy@abspage` (absolute page, by design).

   With those two excluded:
   - every partial run succeeds;
   - **all post-kernel registers equal the full run at every segment boundary**;
   - **every partial-run page is identical to the full-run page with the same label** (75 pages over 6 runs).
4. The only remaining differences are in kernel registers: `\@tempcnta`, `\@savsf`, `\@eqpen`, `\l__cmd_current_arg_int`, `\g__tbl_row_int` (scratch); `\g_shipout_readonly_int`, `\g_shipout_totalpages_int` (absolute, by design); `\g__mark_int` (mark sequence, see S7); the float-box insert counts.

**Consequences for the plan (§6.4.2)**
- **State vector** = LaTeX counters in the kernel checkpoint list (`\cl@@ckpt`) ∪ registers allocated after the kernel (index > `\count10` at `\documentclass`, recorded by `fastinc-ini.sty`), minus a deny list of run-local registers: `Hy@abspage`, `BKM@id`, plus config `[state] ignore`.
  - This matches D1(b), "all minus deny list". The deny list now consists of the kernel range plus run-local registers, not scratch registers: package scratch registers end up equal after restore anyway.
- **Restore** for excluded units: the post-kernel part of the vector (the kernel restores its counters itself).
- **Risk:** a run-local register missing from the deny list breaks the run. A hard TeX error triggers the full-build fallback; a silent error is caught only by the acceptance tests and `fastinc check`. New run-local registers found that way go into the deny list.
- Cost is negligible: about 550 values per record, written with `\immediate\write`.
