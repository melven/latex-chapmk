# S3 — hook order around `\include`, TikZ library hook, graphics hook

**Setup.** TeX Live 2026 (LaTeX 2026-06-01), dev image. Reproducer: `tests/corpus/minimal/S3-hooks/` (`./run.sh OUT`).
- Test document: `article` with three units:
  - `u1`: text plus a `[p]` float, so a page is deferred to the final `\clearpage`;
  - `u2`: a tikzpicture;
  - `u3`: text.
  There is glue text before, between and after them, and `\usetikzlibrary{external}`.
- `s3probe.sty` logs every hook event with `\c@page`, `\ReadonlyShipoutCounter` and whether `\@auxout` is the main aux or the unit aux.
- Runs: full twice, then `\includeonly{u1,u3}`.

**Kernel code** (`latex.ltx`, `\@include`). An included unit does:

```
\clearpage; write \@input{u.aux} to main aux
\@auxout := \@partaux; open u.aux
include/before; \@input@{u.tex}; include/end
\clearpage
include/after
\clearpage
\@writeckpt{u}; close u.aux
```

An excluded unit does `\deadcycles\z@; \@nameuse{cp@u}; include/excluded`. After both branches: `\@auxout := \@mainaux`.
`\@setckpt#1` is `\global\@namedef{cp@#1}`; the checkpoint body is the next brace group.

**Observed** (full run; the partial run is identical except for u2):

| Event | page | shipout | aux |
|---|---|---|---|
| shipout (glue G0) | 1 | 0 | main |
| include/before u1 | 2 | 1 | unit |
| include/end | 2 | 1 | unit |
| shipout ×2 (u1 text, deferred float page) | 2, 3 | 1, 2 | unit |
| include/after | 4 | 3 | unit |
| shipout (glue G1, by u2's first `\clearpage`) | 4 | 3 | main |
| partial run only: `cp@u2` restore begin / end | 5 / 6 | 4 | main |
| partial run only: include/excluded | 6 | 4 | main |
| include/before u3 | 6 | 4 (partial) / 5 (full) | unit |

**Answers**
1. `include/before` comes after the initial `\clearpage`, with the unit aux open and `\CurrentFile` = `u.tex`. This is the correct place to switch to segment `U<k>` and write its entry vector.
2. Pages from the final `\clearpage` (deferred floats) are shipped **between `include/end` and `include/after`**, so `\fastinc@ckpt` belongs at `include/after`. The unit aux is still open there (`\@writeckpt` follows). This confirms the plan fix P2. The switch to glue `G<k>` also happens at `include/after`.
3. `include/excluded` exists, but it runs **after** the checkpoint restore `\cp@u`. The entry vector of an excluded unit (state after the initial `\clearpage`, before the restore) can be recorded by wrapping `\@setckpt` from the aux: `\cp@u` becomes `{<record entry>}<original checkpoint>`. Observed: the wrapper code runs at page 5, before the restore sets page 6. A unit without a checkpoint (never compiled) records no entry; it is dirty anyway (§6.9.1 f).
4. fastinc's own register restore for excluded units belongs at `include/excluded`, after the kernel restore. This matches PLAN §6.4.2(3).
5. The file hook `file/after/tikzlibraryexternal.code.tex` fires on `\usetikzlibrary{external}`, so the externalize neutralisation hook works.
6. Graphics: wrapping `\Gin@setfile{type}{ext}{file}` gives the resolved file name with extension (`a.pdf`) at inclusion time, inside the right segment.

**Consequences for the plan**
- §6.4.2(1)/(2): the excluded-unit entry is recorded by the `\@setckpt` wrapper, not by `include/excluded`. Glue exits `\fastinc@gexit{G<k-1>}` are written at the same point: wrapper or `include/before`.
- §6.4.2(6): the graphics hook point is a wrapper around `\Gin@setfile`.
