# src/chapmk/tex: LaTeX packages

Rules (root CLAUDE.md): LaTeX2e with kernel hooks (expl3 allowed), internal prefix `\chapmk@`,
records and hooks only, no logic. The version in `\ProvidesPackage[... v<version> ...]` must
equal `chapmk.__version__` (checked by `tests/unit/test_tex_packages.py`).
**Keep this file in sync** with the packages.

| File | Loaded | Contents |
|---|---|---|
| `chapmk-ini.sty` | before `\documentclass`: format builds (`gensrc.format_source`), full and reference builds (`gensrc.full_mode_input`) | `\chapmk@kernelcount` (`\count10` at load time = kernel register boundary, S4); externalize redirection on hook `file/tikzlibraryexternal.code.tex/after` (§6.4.3, §6.17): the user's `\tikzexternalize[...]` is called with `mode=convert with system call` and real job `\jobname`; the system-call handler is replaced by `\chapmk@picture` (key = md5 of body, `\chapmk@picstamp`, `\chapmk@picrefs@<seg>` (full mode: `-`), `\chapmk@picstate` only if the code shows counters (`\pdfmatch` with `\chapmk@countersre`), `\linewidth`, font, colour; figure in `\chapmk@picdir` → `\pgfincludeexternalgraphics`, else inline with `\count` registers restored afterwards and a copy of the box shipped as an extra page by the wrapped `\pgfsys@typesetpicturebox`); records `chapmk-picture: x|u|s|f ...` in the log (`s`: code of an exported picture; `f`: file read while exporting, via hook `file/before` and wrapped `\Gin@setfile`); extra-page count `\chapmk@pics`; driver file `chapmk-pics.tex` read at `begindocument/before`; deferral table `\chapmk@deferred` (§6.3.3; S13: in format builds, flagged by `\chapmk@formatbuild`, `\pdfcatalog`/`\pdfinfo`/`\pdfnames`/`\pdftrailer` and their expl3 names are wrapped and recorded there; `\chapmk@pdfunwrapall` restores the primitives; a call without a braced argument sets `\chapmk@pdfunrecorded`); S13: `\chapmk@capturemvl` (format builds, end of the format source) moves the nodes left on the main vertical list (e.g. xcolor's `\pdfcolorstack 0 push`) into the dumped box `\chapmk@mvlbox` via a local output routine |
| `chapmk.sty` | at the split point of incremental runs (`gensrc.run_main`; driver macro `\chapmk@denynames` set before) | records of §6.4.2 / Appendix B, parsed by `records.py`. Segment tracking (`\chapmk@seg`: `P` for the preamble after the split point (its files are global inputs), `G0` from `begindocument/before`; include counter `\chapmk@k`) on `include/before`, `include/after`, `include/excluded` and a `\@setckpt` wrapper. State vector = kernel checkpoint counters plus registers above `\chapmk@kernelcount`, minus deny list (`\chapmk@cvec`), plus one pseudo register `\chapmk@markbase`+`<marks register>` per kernel mark class (`\chapmk@mvec`: digest of the last mark's text after an aux round trip, `\chapmk@mprep` computes them before a vector is written; a changed last mark is an absolute assignment of the segment). Unit end: `\chapmk@mk{<id>}{<class>}{<region_slot>}{<text>}` records (page and column regions) in the unit aux, collected per unit by the `\@setckpt` wrapper and restored for the pseudo registers listed in the checkpoint (`\chapmk@mset`). `.frec`: `K <id> <class>` per class, `K primitive <n>` for a `\marks` register of no class holding a mark (driver: full mode). `\chapmk@vec` is the expandable writer, with prefix `\chapmk@pfx`: `chapmk@b` = baseline, `all` = complete. Checkpoint = complete exit vector; restore after the kernel restore. `\jobname.frec`: `P` page map (PDF page index: shipout counter plus extra picture pages), `F` file/graphics attribution. `.nlo` segment markers. `\setcounter`/`\@stpelt`/`\pagenumbering` wrapped (`\protected`) for absolute sets. Bookmark levels at `enddocument`. Picture cache: records carry `\chapmk@seg`, key state = complete counter vector without marks (`\chapmk@picstate` = `\chapmk@cvec`). Counter registers and reset lists (`\chapmk@counters`, from `\cl@@ckpt` and `\cl@<name>`) at `begindocument/end`. Layout flags (`\chapmk@layout`: twoside, openright); per unit at `include/before`: `O <seg> 0|1` (twoside and openright in effect at the unit start, e.g. a local `open=any`). Elapsed-time records `T <point> <\pdfelapsedtime>` in `.frec` at package load, `\begin{document}`, every segment start and `\end{document}` (M6 breakdown). `T picture+`/`picture-` around every `\pgfpicture` (cmd hooks). eqparbox tags per use: `Q <segment> <tag>` (`\AddToHookWithArguments` on `\eqp@compute@width`, `\eqp@set@min@width`). `L <ext>` record per `\@starttoc{<ext>}` (list files of any extension). List-file markers: `\chapmk@ustart{U<k>}` as the first unit-aux statement and the `\chapmk@entry` handler write `\chapmk@lmark{U<k>}` / `{/<seg>}` (no-op) into the open list files (`\chapmk@listexts`: default = `facts.DEFAULT_LIST_SUFFIXES`, set by the run main to the document's list files) while the aux files are read at `\end{document}`. At load (the split point): puts back the nodes of `\chapmk@mvlbox` (`\unvbox`, S13), runs the deferral table, then `\chapmk@pdfunwrapall` (S13). **No registers allocated** (they would enter the vector). |

The driver finds the packages through `TEXINPUTS` (`texdist.TeXLive.environment`).
