# src/fastinc/tex: LaTeX packages

Rules (root CLAUDE.md): LaTeX2e with kernel hooks (expl3 allowed), internal prefix `\fastinc@`,
records and hooks only, no logic. The version in `\ProvidesPackage[... v<version> ...]` must
equal `fastinc.__version__` (checked by `tests/unit/test_tex_packages.py`).
**Keep this file in sync** with the packages.

| File | Loaded | Contents |
|---|---|---|
| `fastinc-ini.sty` | before `\documentclass`: format builds (`gensrc.format_source`), full and reference builds (`gensrc.full_mode_input`) | `\fastinc@kernelcount` (`\count10` at load time = kernel register boundary, S4); externalize redirection on hook `file/tikzlibraryexternal.code.tex/after` (§6.4.3, §6.17): the user's `\tikzexternalize[...]` is called with `mode=convert with system call` and real job `\jobname`; the system-call handler is replaced by `\fastinc@picture` (key = md5 of body, `\fastinc@picstamp`, `\fastinc@picrefs@<seg>` (full mode: `-`), `\fastinc@picstate`, `\linewidth`, font, colour; figure in `\fastinc@picdir` → `\pgfincludeexternalgraphics`, else inline with `\count` registers restored afterwards and a copy of the box shipped as an extra page by the wrapped `\pgfsys@typesetpicturebox`); records `fastinc-picture: x|u|s ...` in the log (`s`: code of an exported picture); extra-page count `\fastinc@pics`; driver file `fastinc-pics.tex` read at `begindocument/before`; empty deferral table `\fastinc@deferred` (§6.3.3) |
| `fastinc.sty` | at the split point of incremental runs (`gensrc.run_main`; driver macro `\fastinc@denynames` set before) | records of §6.4.2 / Appendix B, parsed by `records.py`. Segment tracking (`\fastinc@seg`, include counter `\fastinc@k`) on `include/before`, `include/after`, `include/excluded` and a `\@setckpt` wrapper. State vector = kernel checkpoint counters plus registers above `\fastinc@kernelcount`, minus deny list. `\fastinc@vec` is the expandable writer, with prefix `\fastinc@pfx`: `fastinc@b` = baseline, `all` = complete. Checkpoint = complete exit vector; restore after the kernel restore. `\jobname.frec`: `P` page map (PDF page index: shipout counter plus extra picture pages), `F` file/graphics attribution. `.nlo` segment markers. `\setcounter`/`\@stpelt`/`\pagenumbering` wrapped (`\protected`) for absolute sets. Bookmark levels at `enddocument`. Picture cache: records carry `\fastinc@seg`, key state = complete state vector (`\fastinc@picstate`). Counter registers and reset lists (`\fastinc@counters`, from `\cl@@ckpt` and `\cl@<name>`) at `begindocument/end`. Layout flags (`\fastinc@layout`: twoside, openright). Elapsed-time records `T <point> <\pdfelapsedtime>` in `.frec` at package load, `\begin{document}`, every segment start and `\end{document}` (M6 breakdown). `T picture+`/`picture-` around every `\pgfpicture` (cmd hooks). eqparbox tags per use: `Q <segment> <tag>` (`\AddToHookWithArguments` on `\eqp@compute@width`, `\eqp@set@min@width`). List-file markers: `\fastinc@ustart{U<k>}` as the first unit-aux statement and the `\fastinc@entry` handler write `\fastinc@lmark{U<k>}` / `{/<seg>}` (no-op) into the open list files (`\fastinc@listexts`, must equal `canon.LIST_SUFFIXES`) while the aux files are read at `\end{document}`. **No registers allocated** (they would enter the vector). |

The driver finds the packages through `TEXINPUTS` (`texdist.TeXLive.environment`).
